

Assignment 15 provided valuable practical experience in contributing to software projects using professional open-source development workflows. Unlike previous assignments that focused primarily on developing my own project, this assignment required me to work with repositories created by other developers. This helped me understand the importance of collaboration, communication, and maintaining code quality when working in a team environment.

One of the most important lessons I learned was how GitHub issues, branches, pull requests, and code reviews are used together to manage software development. Before making any changes, I had to identify suitable issues, understand the project structure, create a dedicated branch, implement the required changes, and submit a pull request for review. This process reinforced the importance of following established workflows rather than making direct changes to the main branch.

My first contribution involved adding additional unit tests to the CourseService component of the Smart Campus Connect project. This task helped me gain a deeper understanding of software testing and the role of unit tests in validating business logic. I created tests for course creation, validation, updates, and deletion while ensuring that all tests passed successfully. Through this contribution, I learned how testing improves software reliability and helps detect defects before deployment.

My second contribution focused on improving the formatting and organization of the README file in the Hospital Vital Monitoring System repository. Although this was a documentation task, it demonstrated that software projects require more than just code. Clear documentation improves usability, helps new contributors understand the project, and enhances maintainability. I learned how proper markdown formatting, heading structures, and navigation elements such as a table of contents can significantly improve the quality of project documentation.

My third contribution involved improving developer documentation by adding a detailed docstring to the create_booking method in the Hospitality Management System repository. This task highlighted the importance of writing self-explanatory code and providing sufficient documentation for future developers. By documenting method parameters, return values, and exceptions, I helped improve code readability and maintainability.

One challenge I encountered was understanding unfamiliar codebases. Since I did not originally develop these projects, I first had to study the existing structure and understand how the different components worked together before making changes. Another challenge was ensuring that only relevant files were included in commits and pull requests. This required careful use of Git commands and verification before pushing changes.

Overall, this assignment strengthened my GitHub workflow skills and provided practical experience with collaborative software development. I gained confidence in working with branches, creating pull requests, resolving issues, writing tests, and improving documentation. The experience demonstrated that successful software development depends not only on coding ability but also on communication, documentation, testing, and adherence to development processes. These are valuable skills that I will continue to apply in future academic and professional projects.
